# Packages

Shared OmniBridge platform packages live here.

Expected packages:

- `canonical-graph`: graph primitives, node identity, edge types, provenance, and versioning.
- `corridor-sdk`: typed contract used by migration corridors.
- `connector-sdk`: typed contract used by source and target platform connectors.
- `workflow-engine`: project lifecycle, state transitions, approvals, and workflow runs.
- `estimator`: project cost, effort, complexity, and agent usage estimation.
- `blueprint-engine`: migration blueprint generation and versioning.
- `rules-engine`: deterministic readiness and validation rules.
- `agent-tools`: typed tool contracts exposed to AI agents.
