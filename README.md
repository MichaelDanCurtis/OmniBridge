# OmniBridge VMware-to-Azure

This repository contains the first migration corridor for the OmniBridge Migration Factory: VMware-to-Azure.

OmniBridge is designed as an AI-assisted migration factory that discovers source environments, builds a canonical technology graph, generates priced migration blueprints, and executes approved migration workflows through deterministic engines.
