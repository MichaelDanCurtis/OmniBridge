# Corridors

Migration corridors live here.

A corridor teaches OmniBridge how to move from one source environment to one target environment using the shared platform factory.

Initial corridor:

- `vmware-to-azure`

Future corridors may include:

- `vmware-to-aws`
- `vmware-to-gcp`
- `aws-to-azure`
- `domino-to-azure-ml`
